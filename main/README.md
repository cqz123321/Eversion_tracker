# Eversion robot tracker (肠道假体内翻机器人追踪)

依赖: `pip install opencv-python numpy PySide6 imageio-ffmpeg`
(没有 imageio-ffmpeg 时导出视频退回 OpenCV mp4v, 文件大 10-30 倍)

```
python gui.py                      # 默认打开上级目录中的 *1379*.mp4
python gui.py "..\Mvi 1378.mp4"
```

## 三个阶段 (右侧标签页)
1. **标注**
   - 起点帧 (机器人还没进入, 基线): 画肠道边缘 (闭合多边形) 和中心线 (头 H → 尾 T)。
   - 终点帧 (推荐, 机器人走到最远处): 画终点边缘和中心线 (可先复制起点曲线再拖点)。追踪到终点停止;
     终点曲线把形状保持的目标从起点形状逐渐过渡到终点形状 (防漂移), 并用终点帧的信号给每个截面归一化。
   - 尖端标注 (可选, 任意帧, 个数不限): 尖端轨迹经过这些点。终点帧机器人没到 T 时, 在终点帧也标一个。
   - 条带颜色 (可选): 在条带上点几下, 阶段 3 用 `条带颜色容差` 忽略条带上的采样点。
   拖动点移动, 点在线段上插入, 右键删除。开始追踪时自动保存为 `<视频名>_annotation.json`, 下次打开自动载入。
2. **追踪肠道**: 边缘点/中心线点跟随光流; 边缘吸附到图像边缘, 中心线往截面中点修正。
3. **尖端**: 中心线分 100 个截面, 每个截面算相对基线的信号 (颜色变化/变暗/变宽…), 尖端 = 机器人到达的最靠尾部的截面。
   `global` 规则在整段视频上求最合理的单调尖端轨迹 (动态规划), 对条带/光照造成的短暂误报最稳。
   下方左: 当前帧信号剖面; 右: kymograph (横轴时间, 纵轴 H→T, 白线 = 尖端, 绿圈 = 尖端标注), 点击可跳转。

暂停时改阶段 2 参数会立即重算当前帧; 改阶段 3 参数 (包括条带容差、亮度权重) 会瞬时重算所有已追踪帧。
往回拖进度条 = 回看 (不丢结果); 从回看位置再播放 = 从那里重新追踪。
`⟲ 回放模式` 打开时, 播放/单步/拖进度条只显示已追踪的结果, 不重新追踪 (`倍速` 控制回放速度)。
`✎ 播放中修正尖端`: 不暂停, 左键点尖端 = 该帧的尖端标注; 按住左键跟着尖端移动, 经过的每帧都标上; 右键删除。

## 速度
解码之后, 与曲线无关的逐帧图像计算 (光流、边缘图、颜色) 在线程池里提前并行算 (`pipeline.py`, 默认 12 线程),
播放时界面每秒只刷新约 15 次。`⏩ 追踪到终点` 不逐帧显示, 约 200 帧/s (640 px 处理宽度)。

## 文件
- `geometry.py` 曲线工具; `flowfield.py` 光流; `colon.py` 追踪 + 尖端; `pipeline.py` 并行预处理; `viz.py` 绘图; `gui.py` 界面
- 导出: `*_track.csv` (每帧尖端截面/弧长/坐标, 原视频像素), `*_curves.jsonl` (每帧边缘和中心线), 视频
